# StarterGui

В этом MVP весь интерфейс создаётся кодом из клиентских скриптов
(`StarterPlayer/.../Client/`), а не вручную в Studio.

Поэтому здесь пока пусто. Папка нужна, чтобы Rojo корректно сопоставил сервис
`StarterGui`. В будущих версиях сюда можно класть готовые UI-объекты
(например, экспортированные из Studio), если захочешь рисовать интерфейс руками.
