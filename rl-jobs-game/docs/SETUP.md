# Установка в Roblox Studio (пошагово)

Это инструкция для человека, который **не программист**. Делай по шагам.

Проект хранит код в обычных файлах (так принято в больших проектах). Чтобы
этот код попал в Roblox Studio, используется бесплатный инструмент **Rojo**.

---

## Вариант A — через Rojo (рекомендуется)

### Шаг 1. Установи Rojo

1. Зайди на сайт https://rojo.space и скачай Rojo (или установи через
   менеджер `aftman`/`rokit`, если умеешь).
2. Установи **плагин Rojo** прямо в Roblox Studio:
   - Открой Studio → вкладка **Plugins** → **Manage Plugins** → найди «Rojo».

### Шаг 2. Запусти сервер Rojo

1. Открой терминал (командную строку) в папке `rl-jobs-game/`.
2. Введи команду:
   ```
   rojo serve
   ```
3. Увидишь сообщение, что сервер работает (обычно на адресе `localhost:34872`).

### Шаг 3. Подключи Studio

1. В Roblox Studio открой новый пустой Baseplate.
2. Нажми кнопку плагина **Rojo** → **Connect**.
3. Весь код из папки `src/` автоматически появится в нужных местах:
   - `ReplicatedStorage → Shared`
   - `ServerScriptService → Server`
   - `StarterGui`
   - `StarterPlayer → StarterPlayerScripts → Client`

### Шаг 4. Включи нужные сервисы (один раз)

1. **Game Settings → Security → Enable Studio Access to API Services** = ВКЛ
   (нужно для сохранений DataStore; без этого сохранения работают только
   в памяти на время сессии — игра всё равно запустится).
2. **Game Settings → Security → Allow HTTP Requests** = ВКЛ
   (нужно только если будешь подключать скрытый сервис живых диалогов; без
   него игра работает на заготовленных русских фразах — это нормально).

### Шаг 5. Запусти

Нажми **Play** (F5). Должно появиться главное меню на русском:
**Новая жизнь / Загрузить жизнь / Настройки**.

## Вариант B — вручную (без Rojo)

Если не хочешь ставить Rojo, можно скопировать код руками. Это дольше и легче
ошибиться, но возможно.

Соответствие папок и сервисов Roblox:

| Папка в проекте | Куда в Studio | Тип объекта |
|---|---|---|
| `src/ReplicatedStorage/Shared/` | ReplicatedStorage → папка `Shared` | ModuleScript-ы |
| `src/ServerScriptService/Server/` | ServerScriptService → папка `Server` | см. ниже |
| `src/StarterPlayer/.../Client/` | StarterPlayer → StarterPlayerScripts → `Client` | см. ниже |

Правила имён файлов Rojo (важно для ручного способа):
- `init.lua` → это сам объект-папка как **ModuleScript** (содержимое папки —
  его дети).
- `init.server.lua` → папка как **Script** (серверный).
- `init.client.lua` → папка как **LocalScript** (клиентский).
- `что-то.lua` → **ModuleScript** с этим именем.
- `что-то.server.lua` → **Script**.
- `что-то.client.lua` → **LocalScript**.

То есть, например:
- `Server/init.server.lua` + остальные `Server/*.lua` → в Studio это
  **Script** с именем `Server`, внутри которого лежат **ModuleScript**-ы
  (`DataManager`, `EconomyManager`, и т.д.).
- `Client/init.client.lua` + `Client/*.lua` → **LocalScript** `Client`
  с **ModuleScript**-ами внутри.
- `Shared/Localization/init.lua` + `ru.lua` + `en.lua` → **ModuleScript**
  `Localization` с детьми `ru`, `en`.

## Что должно работать в MVP

1. Главное меню (русский).
2. Экран **5 слотов жизни**.
3. Выбор сложности: **Лёгкий** и **Обычный** доступны, **Сложный**
   заблокирован (откроется после $1,000,000 всего заработано в Обычном),
   **Невозможный** — «Скоро».
4. Случайная семья.
5. Детство с 4 лет: текст сцены + кнопки «Говорить» с NPC.
6. **Свободный ответ**: игрок сам пишет текст в поле, NPC отвечает живо
   (или заготовленной русской фразой, если внешний сервис не подключён).
7. Переход во взрослую жизнь и итог детства.
8. HUD: имя, возраст, деньги, репутация.

Экономика (переводы, чаевые) и работа в ресторане/курьером реализованы на
сервере и готовы к подключению UI в следующей версии.

## Частые проблемы

- **Меню не появилось** — проверь, что `Client` это LocalScript в
  StarterPlayerScripts, а `Server` — Script в ServerScriptService.
- **Сохранения не сохраняются между запусками Studio** — это нормально без
  «Enable Studio Access to API Services». На реальном сервере всё сохранится.
- **NPC всегда отвечают одинаковыми фразами** — значит внешний сервис живых
  диалогов не подключён. Это ожидаемо для базовой версии (см. `BACKEND.md`).
