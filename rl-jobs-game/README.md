# Rl Jobs- Real life Jobs

Roblox life/job simulator про реальную жизнь, взросление, профессии, деньги,
отношения, репутацию и живой город.

> **Главная идея:** Ты не просто выбираешь работу — ты вырастаешь человеком,
> которым становишься.

Игрок начинает ребёнком (примерно 4 года), проживает детство (первые 20–30
минут — это пролог жизни), делает выборы, которые влияют на характер,
отношения и репутацию, а затем выходит во взрослую жизнь и устраивается на
первую работу в живом городе.

---

## ⚠️ Самые важные правила проекта

1. Название игры всегда: **Rl Jobs- Real life Jobs** (не переименовывать).
2. Основной язык игры — **русский**. Английский — только как будущая локализация.
3. **Никогда** не упоминать игроку ИИ, нейросети, Gemini, AI и т.п. Это скрытая
   техническая система. Игрок видит только обычные игровые слова: «Говорить»,
   «Ответить», «Работа», «Память», «Город» и т.д.
4. Все важные значения (деньги, опыт, открытия, переводы) считает и проверяет
   **сервер**. Диалоговая система не управляет экономикой напрямую.
5. Hard открывается только после **$1,000,000 total earned** (всего заработано)
   в Medium — на весь аккаунт, а не на один слот.

## Что уже сделано в этом MVP-скелете

Это стартовая, но **связная** кодовая база. Главная цепочка идеи реализована:
детство → выборы → отношения → взрослая жизнь → первая работа → живой город.

| Система | Файл |
|---|---|
| Конфигурация (сложности, семьи, экономика, лимиты) | `Shared/Config.lua` |
| Локализация (русский основной + язык аккаунта Roblox) | `Shared/Localization/` |
| Сетевые каналы (RemoteEvent/Function) | `Shared/Remotes.lua` |
| Сохранения: 5 слотов жизни + данные аккаунта | `Server/DataManager.lua` |
| Сложности (Easy/Medium/Hard/Impossible) | `Server/DifficultyManager.lua` |
| Случайная семья (6 типов с плюсами/минусами) | `Server/FamilyManager.lua` |
| Характеристики игрока | `Server/StatsManager.lua` |
| Отношения и память NPC | `Server/RelationshipManager.lua` |
| Экономика, total earned, открытие Hard | `Server/EconomyManager.lua` |
| Перевод денег между игроками + комиссия/лимиты | `Server/TransferManager.lua` |
| Чаевые | `Server/TipManager.lua` |
| Свободные диалоги (скрытый backend + fallback) | `Server/DialogueServer.lua`, `Server/DialogueBackend.lua` |
| Фильтрация текста | `Server/SafetyFilter.lua` |
| Этапы детства (4–6, 7–10, 11–14, 15–18) | `Server/ChildhoodManager.lua` |
| Ресторан + замена NPC игроком | `Server/RestaurantManager.lua` |
| Курьер | `Server/CourierManager.lua` |
| Клиент: меню, слоты, диалоги | `StarterPlayer/.../Client/` |

Скрытый backend (генерация живых ответов NPC) описан в
[`docs/BACKEND.md`](docs/BACKEND.md). Если backend недоступен — игра использует
заранее написанные русские fallback-фразы и **не ломается**.

## Как это открыть в Roblox Studio

Подробная пошаговая инструкция на русском: [`docs/SETUP.md`](docs/SETUP.md).

Кратко: проект использует **Rojo** (стандартный способ держать код Roblox в Git).

1. Установи Rojo (плагин в Studio + командную строку).
2. В папке `rl-jobs-game/` запусти: `rojo serve`.
3. В Studio нажми **Connect** в плагине Rojo.
4. Весь код из `src/` появится в нужных сервисах (ReplicatedStorage,
   ServerScriptService, StarterGui, StarterPlayer).
5. Нажми **Play** — увидишь главное меню на русском.

Если ты не хочешь ставить Rojo — в `docs/SETUP.md` есть и ручной способ
(скопировать код в скрипты вручную).

```
rl-jobs-game/
├── default.project.json        # карта Rojo: какие папки в какие сервисы
├── docs/
│   ├── SETUP.md                # пошаговая установка в Roblox Studio
│   └── BACKEND.md              # скрытый backend для живых диалогов
└── src/
    ├── ReplicatedStorage/Shared/      # общий код (клиент + сервер)

    ├── StarterPlayer/.../Client/      # клиентский код
    └── StarterGui/                    # UI создаётся кодом
```
